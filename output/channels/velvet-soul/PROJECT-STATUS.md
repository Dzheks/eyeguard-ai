## Дальше по плану (порядок)
1. Сгенерить серию треков с ротацией Track A/B/C/D тегов (под Persona Velvet Soul Vocal), скачать в WAV
2. Прогнать каждый трек через Bandlab — мастеринг, preset "universal", 50% strength
3. Склеить несколько треков в видеоредакторе в один непрерывный микс 90–120 мин
4. Сгенерить hero-изображение (одна из 3 готовых вариаций из velvet-soul-clone.md) → анимировать в Veo3 (8 сек, бесшовный луп) → растянуть/зациклить на всю длину видео
5. Свести аудио-микс + видео-луп в один файл
6. Залить на YouTube: заголовок из готового списка 10 тайтлов, превью — один из 5 готовых thumbnail-концептов
